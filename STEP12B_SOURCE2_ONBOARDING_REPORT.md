## Factory changes completed

### 1. Source-neutral raw fragment schema v1.1

New: `schemas/raw_fragment.schema.v1.1.json`

Adds a source locator independent of PDF coordinates:

- `page_bbox`
- `web_line_range`
- `css_selector`
- `json_path`

For HTML, `source_page` and `bbox` may be null.

### 2. Canonical knowledge schema v1.2

New: `schemas/knowledge_object.schema.v1.2.json`

Adds `source_locator` to canonical provenance fragment references and supports
`coordinate_status = not_applicable` for sources where PDF geometry is meaningless.

Schema v1.1 was not mutated. Existing Fractuurpreventie hashes and review snapshots remain
bound to their original contract.

### 3. Generic HTML extractor

New: `src/extract_html_v1.py`

Properties:

- deterministic;
- local-file only; no hidden network retrieval;
- extracts visible `h1-h6`, `p`, and `li` blocks;
- skips script/style/noscript/svg content;
- preserves heading hierarchy;
- creates stable raw-fragment hashes;
- records web line locators.

### 4. Generic semantic transform

New: `src/semantic_transform_generic_v1.py`

The transformer has no guideline-specific clinical rules. A versioned semantic spec maps
raw fragment IDs to canonical object types, logic, relations and risk fields.

This is the intended factory pattern for additional sources.

### 5. CLI integration

New commands:

- `vvn-data-service extract-html`
- `vvn-data-service semantic-generic`

### 6. Source 2 manifest

New: `data/source_manifest.continentie.v1.json`

The manifest is intentionally publication-blocked until an exact source binary is locally
available and hash-verified.

## Compatibility repair

The first fail-closed prepublication run found that the integrity kernel still recomputed raw-fragment hashes using the PDF-era field set. Protocol v2.1 raw fragments add `source_locator`, so valid HTML fragments were initially flagged as hash mismatches. The kernel now selects the hash field set by fragment version/shape: legacy PDF fragments retain their original hash contract, while source-neutral fragments include `source_locator`. This preserves all existing hashes and makes HTML provenance verifiable.

The repeated prepublication run has zero raw-fragment hash errors and remains blocked for the intended reasons: source integrity and review state.
